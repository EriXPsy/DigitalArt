# 如梦幻泡影 · 数字视觉诗歌

> 一切有为法，如梦幻泡影，如露亦如电，应作如是观。 ——《金刚经》

一个基于浏览器的实时交互视觉作品。通过电脑摄像头捕捉用户的身体轮廓与动作轨迹，将其解构、转化为**光、墨、泡沫**等视觉意象，诠释东方美学中「人并非固定实体，而处于流动、聚散与幻象之中」的命题。

## 概念

摄像头在这里不是输入设备，而是一面「镜」：观众看到的不是自己，而是「自己正在消散的证据」。作品追求高流畅度、极低视觉延迟、干净而有呼吸感的材质演变，而非重度 3D 建模或复杂的算力架构。

## 技术构成

- **渲染**：HTML5 + [Three.js](https://threejs.org/)（WebGL），自写 GLSL 着色器，全屏后期（UnrealBloom 等）。
- **感知**：[MediaPipe Selfie Segmentation](https://developers.google.com/mediapipe) 实时人体轮廓分割；[MediaPipe Hands](https://developers.google.com/mediapipe) 手势追踪。
- **物理 / 视觉**：Simplex Noise 力场、粒子系统、平流与扩散。
- **零构建**：通过 `importmap` + CDN 直接运行，无需 `npm install`。

## 篇章（当前 MVP）

- **卷一 · 光（聚散如光）**：轮廓内自发光粒子，动作产生排斥力使其流散。
- **卷二 · 墨（人如墨字）**：以活字意象排布于人体轮廓，墨韵流转。
- **卷三 · 沫（人身如聚沫）**：气泡薄膜覆盖轮廓，聚散生灭。

另含扉页菜单、分步引导、篇章切换、收束圆满页，以及**无需摄像头的观影演示模式**。

## 运行方式

摄像头需在 `https` 或 `localhost` 下才能调用（浏览器安全策略）。

```bash
# 在项目根目录启动本地服务器（任选其一）
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000/幻泡影.html
```

> 直接双击以 `file://` 打开亦可体验，但浏览器可能限制摄像头；此时可使用「无摄像头 · 观影演示」完整体验三卷篇章。

**部署提示**：若使用 GitHub Pages，建议将 `幻泡影.html` 重命名为 `index.html`，Pages 会自动以根路径提供。本作品首次加载需联网拉取 Three.js 等 CDN 资源。

## 状态与路线

当前为 **MVP 单文件原型**。后续方向（规划中）：

- 感知层与渲染层时钟解耦（推理 ~20fps / 渲染 60fps）；
- 以 GPU 上的「形场 / 势场 / 缘场」替代逐像素回读；
- 粒子生灭状态机（「无常」的工程编码）；
- 按章节拆分为可维护的模块化目录。
