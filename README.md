# 如梦幻泡影 · 数字视觉诗歌

> 一切有为法，如梦幻泡影，如露亦如电，应作如是观。 ——《金刚经》

一个运行在浏览器中的实时交互视觉作品。通过电脑摄像头捕捉用户的身体轮廓与动作轨迹，将其解构、转化为**光、墨、泡沫**等视觉意象，诠释东方美学中「人并非固定实体，而处于流动、聚散与幻象之中」的命题。

---

## 一、项目简介与产品定位

摄像头在这里不是输入设备，而是一面「镜」：观众看到的不是自己，而是「自己正在消散的证据」。作品不追求重度 3D 建模或复杂的算力架构，而是追求高流畅度、极低视觉延迟、干净而有呼吸感的材质演变——一种克制、温润、避免「程序员特效」的数字视觉语言。

**产品定位**：一场关于身体、感知与无常的数字视觉诗歌；可作为浏览器交互艺术体验、数字艺术展览或线上展演作品。

## 三、启动方式与环境变量说明

### 本地启动

摄像头调用受浏览器安全策略限制，仅能在 `https` 或 `localhost` 下生效：

```bash
# 在项目根目录启动任意静态服务器（任选其一）
python -m http.server 8000
# 或：npx serve

# 然后浏览器打开
http://localhost:8000/
```

- 直接以 `file://` 双击打开亦可体验，但浏览器会限制摄像头；此时可选择「无摄像头 · 观影演示」完整体验三卷篇章。
- 首次加载需联网，从 CDN 拉取 Three.js 运行时依赖；感知层为纯前端 Canvas2D 实现，无需任何模型 / wasm 下载。

### 环境变量说明

**本项目为纯前端应用，没有后端服务，因此不存在运行时环境变量或密钥配置。** Three.js 等依赖通过公开 CDN 加载，无需申请任何 API Token；感知层用原生 Canvas2D 实现，不依赖任何第三方 CV 库。

唯一与「配置」相关的是页面 `<head>` 中写死的 CDN 地址；若需离线 / 内网部署，可将这些资源本地化后修改对应引用即可，仍无需任何环境变量。

## 四、核心使用流程与 AI 介入环节说明

### 核心使用流程

1. **扉页**：进入作品，阅读题引经文。
2. **授权摄像头**：点击「启动诗意捕捉」授权摄像头；或选择「无摄像头 · 观影演示」以虚拟身影完整体验。
3. **立身明镜前**：站在摄像头前使全身可见（引导层分步提示）。
4. **实时捕捉与呈现**：纯前端 Canvas2D 提取身体轮廓（形场）与运动（势场）——采用选择性背景学习（静止的人体不被背景吸收，故静止时也持续可见）、最大连通域去噪与形态学闭运算（轮廓清晰可辨）、边缘柔化与时间平滑（似光晕/墨韵）。画面随动作流变为光 / 墨 / 泡沫。
5. **篇章切换与收束**：通过底部控制条在「卷一·光 / 卷二·墨 / 卷三·沫」间切换；结束进入「观照圆满」收束页。

### AI 介入环节（透明说明）

本项目的 AI 介入程度有限且透明：

- **AI（DuMate）主要参与**：几轮交互式对话的构思碰撞，以及对**部分 HTML / CSS 动画细节**的修改建议。
- **由作者（人类）主导完成**：整体视觉呈现、创意方向与东方美学的定调，以及大量的调试与问题修复。

换言之，这是一件以人的艺术判断为核心、以 AI 为辅助工具的数字作品，而非由 AI 自动生成。

## 六、篇章与功能（当前 MVP）

- **卷一 · 光（聚散如光）**：轮廓内自发光粒子，动作产生排斥力使其流散。
- **卷二 · 墨（人如墨字）**：以活字意象排布于人体轮廓，墨韵流转。
- **卷三 · 沫（人身如聚沫）**：气泡薄膜覆盖轮廓，聚散生灭。
- 含扉页菜单、分步引导、篇章切换、收束圆满页，以及**无需摄像头的观影演示模式**。
